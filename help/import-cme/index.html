Review a batch of credits before adding it, including duplicates and missing fields.

Transcript import Demonstration records only. No real messages, payments or AI requests occur. Import a transcript from CME Credits. Choose a supported file or paste text. If prompted, match the columns, then review the selected rows. Duplicates begin unticked. Check dates, hours and credit types and correct missing fields. Follow the steps

PDF, CSV or XLSX file, or pasted text. Other PDF layouts may need available AI access.

  1. Open Credentials, then CME Credits and choose Import transcript.
  2. Choose transcript file (PDF, CSV, XLSX), or select Paste text instead. Which formats, which columns? explains the available layouts.
  3. If asked, map the columns and choose Continue to review. Check every included row's title, date, hours and credit type.
  4. Leave duplicates unticked unless you have checked that they are separate activities. Fix missing fields and review topic tags.
  5. Choose Add to CME log when the selection is correct. Check the confirmation and the entries in CME Credits.

Good to know

  • The Add button includes the selected row count and hours. Nothing is added to the CME log until you choose it.
  • Imported transcript rows do not automatically supply individual certificates. Link those from Documents when needed.
  • A known layout describes the parser, not a verification that the credits qualify. Some other PDF layouts are sent to AI; review the import screen's explanation.

You’re done when: The intended activities appear once, with the right fields and total hours.
